# WP-3 test map: TS `it(...)` to Rust test

Short names. Prefixes: `ctx::` = `template::context::tests::`, `ws::` = `workspace::tests::`,
`sk::` = `skills::tests::`, `cb::` = `clipboard::tests::`. Integration tests live in
`tests/prompt_golden.rs` (`golden::`) and `tests/skill_library.rs` (`lib::`).
`golden::every_golden_prompt_renders_byte_exact [x]` means fixture `fixtures/prompts/x.json`, which is
generated by the real TS engine and compared byte for byte (stronger than the TS `toContain`).

## clipboard-service.test.ts

The TS suite mocks `child_process` per platform (osascript / xclip / PowerShell). The Rust service uses
`arboard` behind a `ClipboardBackend` trait (ARCHITECTURE section 4.8), so the platform-specific rows have
no equivalent. Behaviour that survives is mapped.

| TS case | Rust |
|---|---|
| isClipboardToolAvailable: macOS / linux with xclip / linux without / windows / unsupported | N/A: availability is `Clipboard::new().is_ok()`; no `which xclip` probe. Smoke: `cb::the_system_clipboard_never_errors_even_when_headless` |
| detect: macOS PNG / TIFF image | `cb::an_image_wins_over_text` (format detection is arboard's) |
| detect: macOS text ut16 / utf8 | `cb::text_is_text_and_blank_text_is_empty` |
| detect: macOS empty clipboard | `cb::text_is_text_and_blank_text_is_empty` (blank text) |
| detect: macOS / linux / windows returns empty on error | `cb::an_unreadable_clipboard_is_empty`, `cb::a_panicking_backend_degrades_instead_of_propagating` |
| detect: linux image/png, text/plain; windows image, text | `cb::an_image_wins_over_text`, `cb::text_is_text_and_blank_text_is_empty` |
| detect: throws on unsupported platform | N/A: arboard reports unsupported platforms as a failed open, which degrades to Empty (spec section 4.4: total degradation) |
| getClipboardImage: null when text | `cb::text_only_clipboard_has_no_image` |
| null when empty | `cb::an_unreadable_clipboard_is_empty` |
| extracts image on macOS / linux | `cb::image_is_returned_as_a_decodable_png` |
| null when osascript returns error / xclip empty buffer | `cb::malformed_pixel_data_is_no_image`, `cb::an_unreadable_clipboard_is_empty` |
| cleans up temp files on macOS | N/A: no temp file or `rm` (image never touches disk) |
