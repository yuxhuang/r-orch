## Non-goals

Vim editing, persistence of UI preferences, regex/fuzzy search, new widget libraries or borders, new on-disk
fields, CLI/`--json` output or peer-protocol changes. Logs retain their existing filtering controls; new entity
table controls cover Goals, Tasks and Agents. No release or merge is authorized by this spec.

## Constraints

Keep existing actions, read-only detail semantics, stable sorts, bounded activity retention and clipboard
behavior. Keyword matching scans in-memory row metadata, not history files, message bodies or a remote service.
Started/Elapsed are presentation values, not new durable facts or CPU/run-time accounting. Task start may
precede process launch because the run is recorded while Preparing. Terminal updated_at can advance after
a metadata edit; R15 records the lead-ruled disclosure, pending owner notice. No stable task/goal
completion timestamp has been established by this design.

Security checklist:
- Default bind and exposure: no new listener or network endpoint; existing terminal/PTY exposure unchanged.
- Bounds on input size, count and rate: keyword ≤256 Unicode scalar values; enforce on key, paste and restore paths; existing message retention limits unchanged.
- Permissions of files it writes: no new runtime file or preferences store.
- Secrets and environment passed to children: no new children, shell invocations, environment or secret access.
- Untrusted text rendered to a terminal or passed to a shell: reject control characters at input boundaries; render names, aliases and snippets through existing safe display helpers; never interpret keyword text as commands.
