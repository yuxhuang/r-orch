## Constraints and security

No gate production code, dependency, manifest, lockfile, toolchain, AGENTS or team-rule change; no nextest adoption, live rule write, push, PR, merge, release, tag or version action in this authoring task. FS1, D45 and option3 remain accepted, not fixed; earlier failures and timing misses remain recorded.

The PR base is untrusted data: pass through an environment variable and quoted argument, never interpolate into shell source. Fetch history without persisting checkout credentials. Unknown classification and malformed output must not skip the suite. Gate outputs and private raw records have different sharing contracts; upload no raw gate records under the current runbook. No secrets or personal paths belong in public artifacts. CI uses separate ephemeral runner homes per job and makes no cross-job home-integrity claim.
