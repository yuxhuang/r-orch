Add an inactive private SQLite router that binds one caller and the executor's failure state to a borrowed transaction and creates, updates, moves, deletes and reads tasks, agents, teams, runs and messages, with task pages selected, counted and hydrated in the transaction that began them. It reports each fatal stored-data or rollback failure before a callback can catch it, keeps ordinary errors ordinary, and refuses reads and writes after a caught cleanup failure, even while the transaction is open. It has no Storage method, owned session, other entity family, public cursor or authentication, and never opens or commits a transaction; the daemon continues to use file storage.
