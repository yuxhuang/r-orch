Add an inactive library predicate, `orch_engine::disk_floor::below_disk_floor`, that decides from caller-supplied available-space and capacity figures for the data and workspace filesystems whether either is under its floor: the larger of 5 GiB and 5% of that filesystem's capacity, rounded up to a whole byte, where available space equal to the floor is not below it. It reads no disk, refuses no work, opens no attention item and nothing calls it yet, so the daemon neither measures space nor enforces a floor and continues to use file storage.
