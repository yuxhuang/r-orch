Fixed the inactive SQLite Agent, Team, Run and Message mappings so that a time column holds milliseconds only for an RFC 3339 `date-time` (`T` or `t`, a `Z`, `z` or `±hh:mm` offset, a fraction of any length whose digits past the third are zero) inside `0000-01-01T00:00:00.000Z` to `9999-12-30T22:00:00.999Z`, and never for a wider ISO 8601 spelling, a leap second or a fraction finer than a millisecond; the original string is kept either way, and the daemon continues to use file storage.
