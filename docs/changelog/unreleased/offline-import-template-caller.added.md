You can now run `orch import --from <project> --dry-run` to check a stopped 1.0 project without writing anything, and `orch import --from <project>` to copy its prompt templates (UTF-8, up to 64 KB each) into a new SQLite data directory; the import is unfinished, so it copies only templates and always exits 1, an existing destination needs `--resume`, it never writes to the 1.0 project and refuses a destination that is itself a symbolic link, and the daemon continues to use file storage.
